# Happy Birthday, Leah! 🎂

Eine interaktive digitale Geburtstagskarte zu Leahs 21. Geburtstag – gestaltet wie eine kleine App in Rosa, Lila und Pastellgrün.

## So funktioniert die Karte

1. **Umschlag öffnen** – Tippe auf den Umschlag, der Brief gleitet heraus.
2. **Kerzen auspusten** – Tippe auf die Flammen der Kerzen „2“ und „1“ und wünsch dir was.
3. **21 Wünsche entdecken** – Hinter jeder Zahl von 1 bis 21 versteckt sich ein Wunsch für das neue Lebensjahr.
4. **Geburtstagsgruß lesen** – Zum Schluss wartet eine persönliche Nachricht. Mit „Konfetti!“ geht die Party weiter, mit „Nochmal“ startet die Karte von vorn.

## Karte öffnen

Die Karte ist über GitHub Pages erreichbar:

```
https://DEIN-GITHUB-NAME.github.io/leah-21/
```

Sie funktioniert auf dem Handy, Tablet und Computer – einfach den Link im Browser öffnen.

## Technik

- Eine einzige Datei: `index.html` (HTML, CSS und JavaScript)
- Keine Installation und keine weiteren Abhängigkeiten nötig
- Schriftarten: Caveat, Fraunces und Nunito über Google Fonts

## Selbst veröffentlichen

1. Neues öffentliches Repository auf GitHub anlegen.
2. `index.html` und `README.md` hochladen.
3. Unter **Settings → Pages** den Branch `main` und den Ordner `/ (root)` auswählen und speichern.
4. Nach ein bis zwei Minuten ist die Karte unter dem oben genannten Link online.
